# pushsql

Push timestamps and sql durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/pushsql/

## Install / run

```bash
git clone https://github.com/theworker02/pushsql.git
cd pushsql
node src/cli.js
node --test
```
